# 🏗️ منصة إدارة وجدولة ورقابة المشاريع الإنشائية المتقدمة
## Enterprise Construction Project Controls, CPM Scheduling & EVM Platform

منصة سحابية متكاملة واحترافية لإدارة وجدولة المشاريع الإنشائية والهندسية الكبرى وفق أعلى المعايير الدولية (**PMI PMBOK 7th Ed.**, **DCMA 14-Point**, **AACE International**, **FIDIC Red Book 1999/2017**, **ISO 21500**).

---

## 🌟 أبرز ميزات المنصة (Core Features & Workstations)

1. **🏢 محفظة المشاريع التنفيذية (Portfolio PMO Executive Hub)**:
   - لوحة قيادة مركزية لمتابعة عدة مشاريع كبرى في آن واحد وحساب مؤشرات المحفظة التراكمية ($BAC, PV, EV, AC, SPI, CPI$).

2. **📊 لوحة التحكم ومؤشرات الأداء (Interactive Dashboard & KPIs)**:
   - ملخص مالي وزمني فوري، مصفوفة مقترحات وتدابير التصحيح الهندسي المعتمدة، وتتبع صحة الرقابة والمخاطر الحرجة.

3. **🎛️ محاكي السيناريوهات المعقدة ومراقب دقة الأرقام (Complex Multi-Scenario Simulator)**:
   - محاكاة 7 سيناريوهات واقعية معقدة (أزمة سلاسل الإمداد وتضخم الحديد، الظروف الجوية القاهرة، أوامر التغيير وتوسيع النطاق، تعثر مقاولي الباطن، أزمة السيولة وتأخر المستخلصات، خطة التعجيل القصوى 24/7).
   - مختبر تفاعلي لتكوين السيناريوهات (Interactive Scenario Builder) بمقابض سحب ديناميكية.
   - نماذج التنبؤ الأربعة بالتكلفة ($EAC_{\text{Optimistic}}, EAC_{\text{Realistic}}, EAC_{\text{Pessimistic}}, EAC_{\text{Bottom-Up}}$).
   - مراقب دقة الأرقام اللحظي (Real-Time Precision Watchdog) ومخطط تورنادو للحساسية (Sensitivity Tornado).

4. **⚖️ مركز حوكمة وجودة البيانات والمطابقة الموحدة (SSOT Data Governance)**:
   - مصفوفة ركائز الحوكمة الست (شبكة CPM، المطابقة المالية SSOT، سلامة العلاقات والروابط، دقة معادلات EVM، ضوابط فيديك، التسلسل الزمني).
   - زر التنسيق والمطابقة الآلي بنقرة واحدة (**Auto-Harmonize All Data**).
   - إصدار وطباعة **شهادة الحوكمة والاعتماد الرقمي للبيانات (Audit Certificate)** المعتمدة دولياً.

5. **📅 الجدول الزمني التفاعلي والمسار الحرج (Interactive CPM Gantt Canvas)**:
   - مخطط جانت تفاعلي مع دعم التكبير والتصغير (أيام / أسابيع / أشهر)، رسم الروابط والعلاقات المنطقية، ونمط **الشاشة الكاملة المخصص لمخطط جانت فقط**.

6. **🛡️ فاحص الجودة الهندسية DCMA 14-Point & Auto-Fix**:
   - فحص واجتياز المعايير الـ 14 لجودة الجداول الزمنية مع محرك **التصحيح والتعديل الآلي الشامل (Auto-Fix All)** لإلغاء أي مخالفات بنقرة واحدة.

7. **🏛️ الرقابة المالية وضوابط العقود FIDIC (Financial & Contract Controls)**:
   - إدارة خطابات الضمان البنكية (Bank Guarantees & LC).
   - محاسبة المواد المشونة بالموقع (Materials On Site - MOS 80% Rule).
   - حساب تكاليف الإطالة غير المباشرة وغرامات التأخير (Prolongation Costs & Liquidated Damages).
   - معادلة تعديل وتصعيد الأسعار وفق المادة 13.8 (Price Escalation Formula).
   - المطابقة الثلاثية لفواتير الموردين ومقاولي الباطن (3-Way Matching: PO == GRN == Invoice).

8. **📈 تتبع الإنجاز اليومي وسجل مقاولي الباطن (Daily Progress & Subcontractor Ledger)**:
   - تسجيل الإنتاجية اليومية بالكميات التراكمية، والمطابقات الموقعية (WIR/IR)، وفصل التنفيذ الذاتي عن مقاولي الباطن مع احتساب حجز الضمان (10% Retention).

9. **⚖️ تحليل الأثر الزمني ومطالبات التمديد (Time Impact Analysis - TIA)**:
   - محاكاة دقيقة لأحداث التأخير وفق بروتوكول SCL ومطالبات التمديد الزمني التعاقدية (FIDIC Cl. 8.4).

10. **📑 المستخلصات المعتمدة وأوامر التغيير (Interim Payment Certificates - IPC)**:
    - إعداد وتوليد شهادات الدفع المرحلية (IPC 1 to IPC 5) وحساب الاستقطاعات النظامية (الدفعة المقدمة 10%، وحسن التنفيذ 10%).

11. **🏢 النمذجة رباعية الأبعاد (4D BIM Simulation)** و **المخطط الخطي للمشاريع الطولية (Linear Scheduling TILOS)**.

12. **🌐 ثنائية اللغة الكاملة (Full Arabic / English Support)**:
    - زر تبديل اللغة اللحظي مع ضبط محاذاة الواجهة (`RTL` للعربية و `LTR` للإنجليزية) عبر كافة الشاشات والتقارير.

## 🚀 طريقة التثبيت والتشغيل المحلي (Quick Start Guide)

### 1. استنساخ المستودع (Clone Repository)
```bash
git clone <repository_url>
cd project-controls-platform
```

### 2. تثبيت الحزم والمكتبات (Install Dependencies)
```bash
npm install
```

### 3. تشغيل الخادم المحلي للتطوير (Start Local Dev Server)
```bash
npm run dev
```
- سيتم تشغيل المنصة فورياً على الرابط: **`http://localhost:5173`**
- *ملاحظة:* المنصة مزودة بنظام **Offline Local Demo Mode** فائق السرعة يعمل تلقائياً دون الحاجة لإعداد أي قاعدة بيانات خارجية مسبقاً!

## 🏆 معايير ومراجع الهندسة المعتمدة (International Standards)
- **PMI PMBOK 7th Edition**: Earned Value Management (EVM) and Risk Frameworks.
- **DCMA 14-Point Assessment**: Schedule network health, float conservation, and relationship integrity.
- **FIDIC Red Book 1999/2017**: Cl. 8.4 (EOT), Cl. 8.6 (Acceleration), Cl. 13.8 (Price Adjustment), Cl. 14 (IPC & Retentions).
- **AACE International Recommended Practices**: 29R-03 (Forensic Schedule Analysis) and 52R-06 (Time Impact Analysis).
- **ISO 21500**: Guidance on project management and data governance.
